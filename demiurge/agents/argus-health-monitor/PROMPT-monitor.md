# argus-health-monitor-monitor — Watchdog for argus-health-monitor

> Watchdog for argus-health-monitor. Read-only.

## Purpose

Watch the state files below and flag signals that argus-health-monitor health is degrading. Lead agent is `argus-health-monitor`.

## Files watched

| File | Schema |
|------|--------|
| `/opt/data/agents/state/demiurge/argus-health-monitor.json` | `argus-health-monitor.schema.json` |

## Metrics watched

1. `argus-health-monitor.last_run`

## Threshold rules

| `argus-health-monitor.last_run` | null or > 7 days ago | **HIGH** |

## Alert routing

- **CRITICAL / HIGH** — append to `/opt/data/agents/state/coord.json:decisions_for_ivan[]`.
- **MEDIUM** — append to parallel notes file at `/opt/data/agents/demiurge/agents/argus-health-monitor/monitor-notes/YYYY-MM-DD.md` (do NOT mutate state files — schemas are `additionalProperties: false`).
- **LOW** — silent.

## Run procedure

1. Read watched files via `cat ... | python3 -m json.tool`.
2. Validate via `python3 /opt/data/agents/scripts/schema-validate-write.py --strict` for any with schemas. Invalid → HIGH escalation.
3. Evaluate every metric → fire per routing table.

## Suggested cron schedule

Default: daily `0 9 * * *` (morning check before Ivan's review).

## Hard stops

- DO NOT modify any watched file.
- DO NOT auto-fix issues — flag only.
