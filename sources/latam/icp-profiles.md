# ICP Profiles — Paraguay + LATAM Verticals

> **Tickets**: DEMIURGE-059, DEMIURGE-060  
> **Status**: researched 2026-08-26  
> **Confidence**: medium — Rubicón validated; other verticals inferred from market data + pricing constitution

## Executive summary

Primary ICP is **founder-led service businesses with 5–30 employees** in Paraguay, expanding to AR/BR/MX digitally-active SMBs. Decision-maker is the **owner**. Budget sweet spot: **US$240–1,500/mo recurring**. Legal vertical has proof (Rubicón EAS); dental and coaching are next wedges per existing pricing benchmarks.

---

## Rubicón EAS profile — what made legal firms bite

| Factor | Rubicón pattern | Generalized ICP rule |
|--------|-----------------|---------------------|
| Pain | Manual lead intake; no pipeline visibility | **Invisible ops debt** — work happens in WA/email, no system |
| Buyer | Managing partner / founder | Owner with P&L responsibility |
| Trigger | Competitor getting online leads | **Fear of irrelevance** + referral from peer |
| Offer shape | Named pipeline (lead gen), not "AI strategy" | **One workflow, one metric** |
| Price | ~US$240/mo entry | Below psychological "project" threshold |
| Trust | Local team, Spanish, production not demo | **Show running system** on first call |
| Tech comfort | Low–medium | Needs hand-holding; rejects DIY tool soup |

## Vertical segments

### 1. Legal (estudios jurídicos / EAS)

| Attribute | Value |
|-----------|-------|
| PY market size | Thousands of small firms; concentrated Asunción/Central |
| Headcount | 3–25 professionals |
| Pain | Lead gen, intake, follow-up, document prep, founder doing sales |
| Budget band | US$240–1,500/mo; setup US$1.5k–4.5k for premium |
| Tech stack | Email, WhatsApp, Word; rarely CRM |
| Decision-maker | Socio director |
| WTP driver | New matters = direct revenue |
| Distribution | Colegio de Abogados events, referrals, LinkedIn (low) |

**Burnout signal**: Partner answering WA at 10pm; cases lost to slow response.

### 2. Dental (clínicas odontológicas)

| Attribute | Value |
|-----------|-------|
| PY market size | Hundreds urban; high micro density |
| Headcount | 2–15 (dentist + auxiliaries) |
| Pain | Appointment no-shows, recall, insurance paperwork, marketing |
| Budget band | G. 150k–900k/mo (US$20–120) quick-win to premium tiers per constitution |
| Tech comfort | Low; uses Instagram + WA |
| Decision-maker | Owner-dentist |
| WTP driver | Chair time = revenue; empty chair = pain |

**Burnout signal**: Dentist manages Instagram DMs between patients.

### 3. Accounting / contabilidad

| Attribute | Value |
|-----------|-------|
| Pain | Client doc chase, SIFEN compliance, repetitive reporting |
| Budget band | US$300–800/mo |
| Decision-maker | CPA owner |
| WTP driver | Client capacity without hiring |
| Risk | They may build automations themselves — sell **capacity**, not tools |

### 4. Real estate (inmobiliaria)

| Attribute | Value |
|-----------|-------|
| Pain | Lead qualification, listing updates, follow-up |
| Budget band | US$200–600/mo |
| Decision-maker | Broker-owner |
| Distribution | Instagram, WA groups, portales (Infocasas) |

### 5. E-commerce / retail SMB

| Attribute | Value |
|-----------|-------|
| Pain | Inventory, CS, order status, multi-channel |
| Budget band | US$300–1,000/mo |
| Tech comfort | Higher — uses Mercado Libre, MP |
| Note | Competes with platform-native tools |

### 6. Coaching / capacitación / consultoría

| Attribute | Value |
|-----------|-------|
| Pain | Client onboarding, content delivery, scheduling, payment follow-up |
| Budget band | **US$500/mo M-tier** (current product) |
| Decision-maker | Solo founder-coach |
| WTP driver | Scale clients without losing personal touch |
| Language | **"Acompañamiento"** not "coaching" in ES PY market |

**Burnout signal**: Coach manually onboarding each client via WA voice notes.
