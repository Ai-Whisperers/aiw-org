## The "Naming Rules" We Used

1. **First name = real Spanish/English first name**. The org is co-led by Ivan (Paraguayan) and Kiki (the CTO), so Spanish first names feel right. The name has to sound like a person you'd actually meet.
2. **Last name = the function, but readable as a surname**. Examples:
   - `Vendedora` (saleswoman) — Sofía the Vendedora
   - `Vigilante` (watchful) — Camila the Vigilante
   - `Curadora` (curator) — Soledad the Curadora
   - `Portera` (doorkeeper) — Francisca the Portera
3. **When the role has a natural Spanish noun for it, use that noun**. `Redactor` (writer), `Catástrofe` (catastrophe — for chaos testing), `Curadora` (curator).
4. **When there's no good Spanish noun, use English-as-surname**. `Rosterina`, `Multimedia`, `Buscador`.
5. **Same surname for same function across depts**. Diego Vigilante (DevOps) and Bruno Vigilante (AI Safety) and Sergio Guardián (Security) are all "watchers" — the surnames share a pattern even though the names are distinct.
6. **Avoid surnames that clash**. We don't have two "Vigilantes" in the same dept. Engineering has Diego/Bruno/Sergio as three distinct watchers — names + surname both.
7. **Some agents get a nickname in parentheses**. `Maestra Kiki` is the only one whose formal name IS her human name. `Francisca Portera` is "the gatekeeper" — that pun shows the function.
8. **No agent is named "Ivan" or "Kiki" except `coach-ivan` and `coach-kiki`**. Those are meta — the coach that coaches the actual humans.

## How to Use This

In conversation:

- "Bruno flagged 3 hard-stop bypasses today" → the `ai-safety-engineer` did
- "Sofía stalled on 2 leads yesterday" → the `sales-pipeline` did
- "Francisca blocked a Metis send" → the `feasibility-gate` did
- "Diego saw the CPU spike" → the `devops-monitor` did
- "Maestra Kiki delivered Git rebase lesson" → the `kiki-coach` did

In briefs and outbox files, the formal name stays (e.g., `outbox/2026-08-28-sales-pipeline.md`). The human name is for conversation only.

In code/cron/state files, the formal name is canonical. The human name appears in:
- This reference doc
- Briefs and synthesis (when describing the agent)
- Outbox headers (optional — agent name is enough)

The human name is a **nickname**, not a replacement. Use it to make the team feel like a team.
