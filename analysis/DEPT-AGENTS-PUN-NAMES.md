## Cultural Reading

**Pattern #1**: every "watcher" agent (vigilanta, watchdog, monitor) gets a vigilant-themed pun — because the org's AI Safety protocol explicitly names these roles.

**Pattern #2**: every "creator" agent (writer, designer, drafter) gets a female suffix in Spanish — the feminine grammatical default, which gives the org a consistent naming voice without being gendered in English.

**Pattern #3**: the chief role in each dept gets "Jefa" — the female chief. This is deliberate: the org is co-owned by Ivan (CEO/Board) and Kiki (CTO), and the feminine-default naming honors Kiki as CTO.

**Pattern #4**: agent names rhyme with their function. **Saleina** flows. **Investigina** flows. **Culturina** flows. **Finanzina** flows. **Operaciona** has a slight consonant clash (operacionA) which we kept because "operaciona" is also a valid Spanish word ("operates" — third person).

**Pattern #5**: pun names double as team-culture shorthand. When Kiki says "Saleina is stalled today" everyone knows which agent. When Ivan says "Watch the vigilantas" everyone knows the AI Safety chain.
